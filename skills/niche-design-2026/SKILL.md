# Niche design DNA — 2026 cheat-sheet

**`website-niche-maker` is the authoritative per-niche skill — invoke it first.** This is the fast reference: each niche's 2026 look + the conversion pattern that actually works. Rule: **a coffee shop ≠ a SaaS ≠ a law firm.** Match the niche, don't reuse an "animated award-site" template everywhere.

## Food & local
- **Restaurant** — dark/moody or warm-editorial; large food photography; serif display + clean sans; subtle motion. CTA: **Reserve / View Menu**, hours + map above fold.
- **Cafe / coffee** — warm, cozy, hand-crafted; cream/earth tones; rounded type; lots of imagery, light motion. CTA: location/hours, menu, "order ahead".
- **Bakery** — soft, pastel, appetizing close-ups; playful serif; gallery-forward. CTA: order/pickup, specials.
- **Bar / brewery** — dark, bold, textured; condensed display type; gritty imagery; punchy motion. CTA: events, menu, reservations.
- **Salon / spa** — elegant, airy, minimal; muted neutrals; thin serif; calm motion. CTA: **Book now** (online booking), services + price.
- **Gym / fitness** — high-energy, bold, high-contrast; heavy sans; action photos/video; dynamic motion. CTA: **Free trial / join**, schedule.
- **Dental / medical clinic** — clean, trustworthy, calm blues/greens; readable sans; real staff photos; minimal motion. CTA: **Book appointment**, insurance, services.
- **Law / professional** — authoritative, restrained, navy/charcoal/gold; serif headings; sober. CTA: **Free consultation**, practice areas, credibility/results.
- **Trades / contractor** — practical, sturdy, bold; high-contrast; project photos + reviews. CTA: **Get a quote / call now**, service area.
- **Real estate** — premium, photo-led, full-bleed imagery; refined sans/serif; map + listings. CTA: search/listings, **book a viewing**.

## Digital, hospitality & commerce
- **SaaS** — clean, modern, product-led; system fonts done well, gradients-with-restraint; UI screenshots, subtle scroll motion. CTA: **Start free / book demo**, pricing, social proof.
- **Startup** — bold, confident, opinionated; big type; one strong hero claim. CTA: waitlist/sign-up.
- **Agency** — distinctive, design-forward, motion-rich (this is where award-site energy belongs); strong portfolio. CTA: **Start a project**, case studies.
- **Portfolio / personal brand** — minimal, typographic, work-first; personality in details. CTA: contact/hire, selected work.
- **Blog** — readability-first; generous type scale + whitespace; minimal chrome. CTA: subscribe.
- **Hotel** — luxurious, immersive, full-bleed photo/video; elegant serif; rooms + amenities. CTA: **Check availability / book** (rate calendar).
- **Wedding venue** — romantic, elegant, photo-led; script/serif accents; galleries. CTA: **Enquire / tour**, packages.
- **Nonprofit** — warm, human, story-led; real photos; clear impact stats. CTA: **Donate**, get involved.
- **Online course** — outcome-led, credible; clear curriculum + testimonials. CTA: **Enroll**, pricing.
- **E-commerce / DTC / fashion** — product-hero, clean grid, fast; editorial for fashion; strong PDP. CTA: **Shop / add to cart**, reviews, free-shipping bar.

## Universal 2026 quality bar (every niche)
Distinct type (no Inter/Roboto default), restrained color system, real imagery, motion that whispers (150–300ms, compositor-only), mobile-designed (not just responsive), WCAG-AA, fast (Core Web Vitals), clear single primary CTA per section.
